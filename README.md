# Todo App

## How to contribute (Student Workflow)

1. **Fork this repository** to your GitHub account (Click the "Fork" button top-right).
2. **Clone your forked repository** to your local machine using the command:
   ```bash
   git clone https://github.com/<YOUR_USERNAME>/teaching-todolist.git
   ```
3. **Create a new branch** for your changes:
   ```bash
   cd teaching-todolist
   git checkout -b <your-branch-name>
   ```
4. **Make your changes** to the codebase, test in the browser.

5. **Commit your changes** with a descriptive message:
   ```bash
   git add .
   git commit -m "Add feature X"
   ```
6. **Push your changes** to your forked repository:
   ```bash
   git push origin <your-branch-name>
   ```
7. **Create a Pull Request** from your forked repository to the original repository. Go to your fork on GitHub, click on "Pull Requests", then click "New Pull Request". Select your branch and submit the pull request.
